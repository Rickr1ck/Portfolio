Raymond Rick B. Ching — Personal Portfolio
A responsive, accessible personal portfolio showcasing IT certifications, software projects, and interdisciplinary academic research. The site is built with plain HTML, CSS, and JavaScript, so it can be published on GitHub Pages without a build step.
Live website: https://rickr1ck.github.io/Portfolio/
GitHub profile: https://github.com/Rickr1ck
The live URL will work after GitHub Pages has been enabled and deployment has completed. If your repository uses a different name, update the URL above accordingly.

Features
- About: Introduces an IT and academic research background.
- Projects: Fetches up to six public repositories from the GitHub API, excluding forks and archived repositories where supported by the site's filtering logic.
- Certifications: Lists six Microsoft IT Specialist subjects: Java, Databases, Networking, HTML and CSS, Information Security, and Cybersecurity.
- Research: Links to the research documents supplied for the portfolio.
- Responsive layout: Adapts to desktop and mobile screens.
- Accessibility: Includes keyboard-focus styling and reduced-motion support.
- No build tools required: Uses static HTML, CSS, and JavaScript.
